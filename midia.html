➕ Enviar nova mídia para os gestores

Até 10 arquivos por publicação. Arquivos de até 8 MB ficam guardados no próprio app; acima disso (vídeos/Reels), o app envia automaticamente para o GitHub (até 1 GB por arquivo) — é só configurar uma vez, logo abaixo.

⚙️ Arquivos grandes (acima de 8 MB): não configurado
  1. Abra github.com/settings/personal-access-tokens/new (logada na sua conta do GitHub).
  2. Em Token name escreva PoloSync. Em Expiration escolha 1 ano (Custom).
  3. Em Repository access marque Only select repositories e escolha GESTOR-EAD.
  4. Em Permissions → Repository permissions, ache Contents e mude para Read and write.
  5. Clique em Generate token e copie o código que aparece (começa com github_pat_). Cole abaixo.

O código fica guardado só neste navegador (não vai para o banco de dados nem para os gestores).
